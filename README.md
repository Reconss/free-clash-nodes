# free-clash-nodes

Daily auto-fetch of public free Clash/V2Ray subscriptions. Each node is verified to
actually open google.com + youtube.com and pass a real download-speed test before it is
kept. Refreshed daily at 10:00 (Asia/Shanghai).

## Subscribe URL (paste into ClashX / mihomo / OpenClash)

Recommended (GFW-reachable mirror):

    https://fastly.jsdelivr.net/gh/Reconss/free-clash-nodes@main/config/mihomo.yaml

Backup mirror:

    https://ghproxy.net/https://raw.githubusercontent.com/Reconss/free-clash-nodes/main/config/mihomo.yaml

Original raw (needs your own proxy):

    https://raw.githubusercontent.com/Reconss/free-clash-nodes/main/config/mihomo.yaml

## Notes

- Free public nodes can die anytime and are run by third parties; do not use for sensitive logins.
- Most are Japan/IDC relays; streaming unblock is limited.
